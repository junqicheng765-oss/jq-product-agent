# P2 认知与心理引导

来源：PDF 第 58-91 页；P2 V1.0。六项二级能力见第 66-74 页。

正式依据：[包内 P2 定义与案例](../../tc-product-agent/references/standards/P2-cognition.md)。本章为应用性提炼；二级 ID 沿用主包索引。

## 核心认识

识别产品事实与用户心理世界的差距，建立理解、判断、预期、信任和行动的合理条件。P2 主责心理目标及判断；语言、空间、操作、过程和感知共同实现它。

## 六项二级能力

### P2-1 用户心智模型理解能力

识别用户当前对对象、关系、规则、动作与结果的概念和因果理解，以及它来自现实经验、竞品还是本产品历史。判断应复用自然映射、调整事实还是校准认知。证据是用户如何解释和行动，不是团队假设“用户应该懂”。

### P2-2 认知负担控制能力

找出注意、理解、比较、记忆、回忆和规则学习的成本，区分必要复杂性与内部复杂性转嫁。产品可承担计算、保存、关联和回忆。检查跨页拼接、近似选项、强制确认与过早教学。高风险需要保留知情判断，不能以字少、留白多、步骤少证明负担低。

### P2-3 用户行为动机与引导能力

在目标对用户确实有价值时，识别开始、继续、暂停、恢复或拒绝的原因：价值不清、成本、能力、机会、风险还是缺乏合理信心。建立透明、适度、可退出的行动条件。用户拒绝可能合理；签到、奖励和催促不能替代真实价值。

### P2-4 用户预期与信任建立能力

校准用户对行为、结果、范围、时间、风险、不确定性和可逆性的预期。信任来自可预测、可解释、可控、可修正；同时处理信任不足与过度信任。验收让用户说明会发生什么、什么尚不确定、自己能控制什么。

### P2-5 用户认知迁移与习惯形成能力

识别已有经验的正迁移与负迁移，通过情境实践、首次成功、一致反馈和支持渐退建立自主熟练使用。规则变化要修正旧习惯。只有重复使用本身持续创造用户价值时，习惯才是合理结果；一次性、低频、高风险任务不默认追求习惯或频次。

### P2-6 用户心理状态理解与调节能力

识别陌生、等待、失败、高风险、时间压力或能力受限下的焦虑、困惑、挫败、警觉、信心与掌控感。先处理真实风险、信息缺失和失控，再减少不必要焦虑、恢复控制或保留必要警觉。不能只用温柔语气、插画和庆祝掩盖事实。

## 应用方法

1. 记录实际用户的当前解释、预期、能力与情境，区分观察和假设。
2. 比较用户心理模型与 P1 事实，识别造成误判或阻力的差距。
3. 写清期望理解、合理风险感、行动条件与停止条件。
4. 由 P3-P7 形成具体实现，并检查用户是否真正理解而不只是点击成功。
5. 根据首次/熟练、压力/平静、风险/可逆性调整支持，不对所有人使用同等强度。

## 书中案例重构

**删除文件：** 用户默认可以恢复时，若产品实际永久销毁，问题不能归咎于“不认真”。应评估调整行为以符合自然理解，或在不可恢复时校准后果认知。P1 定义后果，P2 判断已有理解，P3 明确表达，P5 提供保护与控制。

**AI 回答：** 流畅、确定的呈现可能制造过度信任。重要任务应让用户理解生成来源、可核查依据和不确定性，保留检查与修正。目标是信任与事实匹配，而不是一律增强信任。

## 验收与失败机制

要求用户复述对象和结果、解释下一步及风险；观察是否能开始、继续、恢复或合理退出；检查提示逐渐减少后能否迁移规律。完成率和点击率只能辅助，不证明理解和自主。

敏感边界：当前理解与认知改变分别归第 1/5 项；心理投入与行动意愿归第 2/3 项；相信什么与此刻感到什么归第 4/6 项。P2 决定目标理解；P3 决定具体措辞；P7 检查感知形式实际造成的心理影响。
