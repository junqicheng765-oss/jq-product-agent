# 感知要求与评审方法

来源：PDF 第 247-277 页的 P7 详细阐述；配合第 235-246 页正式二级能力使用。本文件提供应用方法，不增加能力项、正式评分或职级。

## 一份可判断的感知简报

把笼统风格要求转成以下内容；只填写当前任务相关项：

| 字段 | 应明确的判断 |
|---|---|
| 场景 | 用户、任务、设备、环境、操作阶段和可用通道 |
| 用户状态 | 当前理解、担心、注意资源、身体与认知限制 |
| 产品事实 | 什么已完成、仍未知、可逆、将产生后果；引用事实基线 |
| 首要感知目标 | 用户先注意什么、理解什么，以及为何必须先出现 |
| 次要感知目标 | 支持扫描、比较和判断的内容，不能抢占首要目标 |
| 行为目标 | 用户应能作出什么知情选择或操作 |
| 心理目标 | 合理的信任、风险感、安心程度；避免承诺超过事实 |
| 风险底线 | 关键限制、最终性、操作成本、退出恢复及替代通道 |
| 产品气质 | 与真实价值、场景相符的整体感受及不适合的形式 |
| 验收依据 | 观察哪些理解和行为，覆盖哪些状态和环境 |

目标可从注意、理解、情绪、行动、品质五个角度表达，彼此可能重叠。例如预订确认应让用户先识别总价、日期和关键限制，随后理解优惠；“高级感”不足以说明层级要求。

## 从目标到形式

1. 核对事实与风险，确定必要的信息及最终性。
2. 检查基本可感知：内容是否能看清、听到、识别，替代通道是否可用。
3. 检查层级：首先注意到的是否最重要，比较顺序是否匹配决策。
4. 检查心理作用：形式是否造成过度信任、压力、羞辱或无依据紧迫。
5. 观察真实行动：能否理解后果并完成任务，失败时能否控制和恢复。
6. 检查跨页面、状态、通道的一致性，再判断整体品质。

这是验收依赖，设计可并行探索。先记录事实与目标，再让视觉、声音、触觉、动态等专业方案回应它；拒绝用个人偏好替代验收依据。

## 通道分工与降级

| 事件 | 必须先明确 | 感知检查 |
|---|---|---|
| 操作已接收 | 接收与业务成功是否不同 | 即时线索不能提前宣告最终成功 |
| 仍在处理 | 可否离开、结果从哪找 | 持续线索、后台状态及结果到达含义一致 |
| 需要注意 | 原因、后果和可执行选择 | 强度匹配风险，不让所有提示都抢占注意 |
| 完成或失败 | 最终事实、影响范围、下一步 | 不同通道表达同一结果，非颜色替代可理解 |

冗余应让关键事实在某个通道失效时仍可到达。多通道同时重复强刺激可能增加负担；选择分工、时序和强度。静音、无触觉、减少动态时仍需传递关键事实；考虑公共环境中的隐私与扰人问题。

## 状态与环境验收矩阵

按风险选取组合，记录已观察与待测试，不把列出矩阵视为已经通过：

| 检查组 | 典型观察 |
|---|---|
| 主任务 | 首次、熟练、比较、提交、完成 |
| 风险与异常 | 高风险确认、空状态、失败、离线、结果未知、恢复 |
| 跨页面 | 正常页面、设置、详情、通知、异常页含义与品质一致 |
| 显示模式 | 明亮环境、暗环境、深浅色、高对比 |
| 字体与语言 | 字号放大、长文本、多语言；不截掉风险和关键控制 |
| 通道关闭 | 静音、无触觉、减少动态、非颜色识别 |
| 设备与环境 | 小屏、低性能、噪声、单手、可访问输入 |
| 用户差异 | 普通消费者、商务用户、中年及中老年、不同熟练度 |

用户差异要从真实能力和任务验证，不用年龄标签替代研究。书中提及 WCAG 2.2 等标准作为参考；实际项目需核对适用标准、版本、合规级别、测量单位及例外。此处不把原书数值变成对所有设备和产品的统一门槛。

## 品味的七个观察面

以下是 P7 第七项能力的实践视角，不是另一个正式二级树：

- 价值一致：形式与产品解决的问题、服务关系及风险匹配。
- 克制：刺激和装饰有明确作用，不以删去必要内容换取简洁。
- 比例：强弱、大小、密度和空间分配与任务重要性相称。
- 节奏：连续使用中的视觉、操作、等待与反馈节奏适当。
- 细节完整：边界、空状态、长文本、错误与降级同样周到。
- 一致中有变化：稳定含义下容许有依据的场景变化。
- 长期耐受：重复使用仍舒服可靠，不只第一次惊艳。

“可用、好用、喜欢、强烈偏好”描述体验进展，不能直接换算能力分数或职级。单张截图可提供局部层级和形式证据，不能证明长期偏好。

## 五种验证方法

| 方法 | 用途与局限 |
|---|---|
| 短时第一印象 | 检查首要注意点与气质；不能证明任务完成 |
| 真实连续任务 | 观察理解、决策、操作与等待中的形式影响 |
| 跨页组合观察 | 并看正常、异常、设置等页面，找含义和品质断裂 |
| 移除通道 | 静音、非颜色、减少动态，验证核心信息的替代方式 |
| 长期重复使用 | 观察刺激疲劳、习惯、效率与耐受；一次体验不能代替 |

## 问题语言

使用具体后果描述严重度，不生成模型未规定的分数：

- 阻断问题：无法感知或完成任务，或误读关键风险、结果。
- 重大问题：层级、反馈或心理作用明显偏离目标。
- 一致性问题：相同形式表达不同含义，或同义线索跨场景断裂。
- 品质问题：细节、节奏、比例或跨状态完整性削弱整体体验。
- 优化机会：底线满足后仍有可证实的改进空间。

这些类别可能交叉。结合用户影响、风险、频率和可恢复性排序，而非把类别机械当成固定优先级。

每项评审写清：观察材料、实际现象、预期目标、用户后果、主责与依赖、建议方向、验收方法、证据限制。
