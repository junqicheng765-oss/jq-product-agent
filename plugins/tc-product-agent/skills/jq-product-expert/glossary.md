# 核心术语

按概念层次组织，正式二级能力见各模块。

| 术语 | 含义与用途 |
|---|---|
| 产品本体 | 用户面对的对象、规则、行为、过程及体验；区别于商业、组织或工程能力全集 |
| 用户价值 | 在具体处境中给用户带来的有效改变，不能由收入或点击单独证明 |
| 世界模型 | 产品对象、关系、状态、规则、边界与历史构成的可解释系统，P1 |
| 事实基线 | 当前已确认的对象、关系、动作、状态、规则、范围和结果；推断及未知另列 |
| 领域转译 | 将专业事实、约束、偏好、例外与不确定性转成可执行产品结构，P1 |
| 对象 | 有身份、属性、边界和生命周期的产品事物，P1 |
| 关系 | 对象之间的依赖、归属、关联及作用规则，P1 |
| 状态 | 对象在某时点的事实条件；状态含义和合法转换归 P1，经历变化归 P6 |
| 产品演进 | 新规则、对象或能力加入后保留必要的身份、历史及一致性，P1 |
| 心智模型 | 用户借助已有经验理解产品因果和行为的方式，P2 |
| 认知负担 | 用户理解、记忆、比较和决策的成本；不等于文字数量，P2 |
| 合理信任 | 理解可靠范围、限制与控制后形成的信任，不等于最大放心，P2 |
| 认知迁移 | 将既有理解与习惯带到新情境；不能保证旧规则总适用，P2 |
| 语义 | 概念、动作、状态和复杂信息的文字意义，P3 |
| 产品语言一致性 | 同一概念命名稳定，不同概念可区分，范围和后果一致，P3 |
| 空间与结构 | 对象与功能的组织、位置、分组、进入、导航和连接，P4 |
| 可发现性 | 用户在合适情境能发现入口或操作；入口组织归 P4，操作提示归 P5 |
| 行为反馈闭环 | 用户意图经操作、接收、校验、结果及后续选择得到可理解回应，P5 |
| 控制与恢复 | 用户能中止、退出、撤销或纠正；不可逆时需理解后果与替代处理，P5 |
| 时间过程 | 随时间推进、等待、中断、异步、失败和恢复的经历，P6 |
| 结果未知 | 证据不足以确定成功或失败的事实状态，不能假定可安全重试 |
| 过程连续性 | 跨场景、设备或中断后保留必要状态和工作上下文，P6 |
| 感知目标 | 让特定用户注意、理解和感受什么，并支持何种行为，P7 |
| 感知层级 | 用形式强弱表现重要性、风险和顺序；信息存在不证明被注意，P7 |
| 多感官反馈 | 视觉、听觉、触觉、动态等通道的分工、冗余及替代，P7 |
| 包容性 | 不同能力、年龄、设备、设置和环境仍能感知、理解与使用，P7 |
| 产品品味 | 与价值一致、克制、完整、协调且长期可耐受的整体品质，P7 |
| 主责问题法 | 根据当前必须先作的关键判断定位主责，允许多能力协作 |
| 反事实检验 | 保留主要原因只改变表现手段，检查失败是否继续 |
| 最小观察单元 | 可判断的一段任务、对象或场景，避免扩展为整个品牌结论 |
| 观察快照 | 记录日期、版本、地区、语言、设备、角色、前提与原始材料 |
| S / E / — | 案例解释中的强证据、有效证据、证据不足；不是职级或来源可信度评分 |
| Good / Bad / Mixed | 某观察单元的有效、有问题或混合证据，不是品牌标签 |
| 模型冻结 | 当前案例组合提供足够解释力的项目结论，不是普遍完备性证明 |

详见 [总纲](chapters/ch01-foundation.md) 与 [案例回验](chapters/ch10-case-validation.md)。
