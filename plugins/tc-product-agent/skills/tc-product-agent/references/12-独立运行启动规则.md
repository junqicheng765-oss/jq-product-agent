# 独立运行启动规则

版本：v0.6｜用途：让新的运行环境在不依赖来源项目的前提下正确加载本包

## 1. 每次任务的最低加载

1. 读取 [Agent 工作模式与试验治理](19-Agent工作模式与试验治理.md)，先判定 H/P/E 模式、允许输入、写入范围和停止点；普通产品需求默认 P，只有明确修改或验证 Agent 本身时才是 H/E。
2. 读取 [标准来源与版本清单](00-标准来源与版本清单.md)、[产品Subagent定义](01-产品Subagent定义.md)和[主线运行与会议纪要](22-主线运行与会议纪要.md)。需要产品判断时读取同包 [专家内核](../../jq-product-expert/SKILL.md)及其总纲与相关方法章节；不每次预读全部正式原文。
3. 读取当前任务的既有 `product/00-工作状态.md`、有效确认记录和当前产品正文；存量项目先按 [17-存量项目输入来源清单与冲突扫描](17-存量项目输入来源清单与冲突扫描.md) 盘点来源、版本和冲突，再决定哪些资料可作为当前输入；没有历史则明确从 S1 开始。
4. 按当前主问题选择 P1-P7 方法和必要协作能力。关键规则、权限、不可逆损失、结果未知、定义歧义/冲突及正式质量门结论，须回查对应正式条款并记录定位；总纲或通用原则存疑时回查 `standards/00-foundation.md`。相关段落不足时再扩大读取，不只依赖 48 项名称，也不重复全量加载。
5. 读取与当前动作有关的运行文档：首轮澄清读 03，建模读 05，场景读 14，评审读 04/06/10/11/14（09 保留为未使用专家内核时的兼容入口），默认交付与设计读 02/13/15，研发交接和实现验收读 13/16，存量输入处理读 17，会议纪要和 A–F 门读 22，Demo 制作/复核读同包 `$jq-demo-quality`，实际 Figma 写入前读 18；H/E 模式与 Agent 质量评估读 19/20，发布前读 21。

## 2. 阶段加载与使用

| 阶段 | 必须使用的运行依据 | 方法路由与正式标准回查范围 |
| --- | --- | --- |
| S1 需求澄清 | 01、03、22；存量项目加读 17 | 00-foundation；按疑点选 P1-P7 |
| S2 目标与范围 | 01、02、07 | 00-foundation、P1；必要时 P2 |
| S3 对象与规则 | 01、02、05、07 | P1；涉及认知/表达/权限呈现时加读 P2/P3 |
| S4 功能与流程 | 01、02、05、07；复杂系统加读 14 | P1、P5、P6；按信息与结构问题加读 P3/P4 |
| S5 体验要求 | 01、02、07、08 | P2-P7 中与实际设计问题相关者；不得跳过 P1/P6 的行为事实 |
| S6 评审与修正 | 04、06、10、11、14；按需专家内核或兼容入口 09 | 00-foundation 及所有适用 P1-P7 的相关条款 |
| S7 定稿与交接 | 02、07、08、11、13；按接收者加读 15/16；实际 Figma 写入加读 18 | 支撑当前交付结论的正式标准与未闭合问题对应标准 |

S1–S7 用于内部生产与审计；对使用者展示 A–F 判断门，合并审阅规则以 22 为准。不能因为跳过了单独 S 步骤会议，就跳过它的质量证据。

表中模块先路由到专家内核对应方法；正式回查按第 4 条触发条件和质量门适用范围执行，不要求每次读完整模块。方法与原文冲突以原文为准。

## 3. 输出前的强制判断

- 每个结论标记为用户要求、来源事实、待验证假设或 Subagent 建议之一。
- 正式评审与质量门对 48 项能力先判定是否适用，再给证据结论；日常生成只使用当前相关能力。“未适用”必须有任务范围依据，不能用于回避检查。
- 不用平均分、文档数量、页面数量或主流程通畅抵消目标、对象、状态、规则、权限、不可恢复损失或结果未知等阻断缺口。
- 任何需要人确认的节点，给出真实可打开的文件、版本、审阅范围、重点、可回复方式和确认后的推进动作。
- P 模式结束前，分别说明产品基线、产品原型/设计交付物和研发交接包的真实状态；没有可操作原型证据时不得称默认完整交付完成。
- E 模式按 [Agent 运行质量与评分规范](20-Agent运行质量与评分规范.md) 评价 Agent，不用 48 项产品能力评分替代运行质量。

## 4. 不可替代的外部输入

本包提供产品工作能力，不提供行业真实规则、企业授权、合规判断、存量系统接口、用户研究结论或品牌资产。缺少这些输入时，继续完成不依赖它们的工作，并将缺口、影响决定、所需来源和责任方写入产品台账；不可凭经验补成确定事实。
