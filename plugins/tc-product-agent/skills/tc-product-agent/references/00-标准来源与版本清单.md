# 标准来源与版本清单

版本：v0.5 运行包清单｜状态：正式能力标准沿用 v0.4 冻结参考层

## 1. 目的与独立性

本文件声明 JQ Product Agent 主 Skill 内的正式能力参考层。安装本 Plugin 即随附所需的 `references/` 与 `sources/`，不要求读取来源项目、外部 Skill、历史会话或其他文件路径。

本包分为两层：

- **运行层**：`references/01-22` 文档，定义角色、流程、产出、评审、存量输入处理、会议纪要、设计/研发交接、工作模式、Agent 质量和发布校验；同包的 `jq-demo-quality` 提供 Demo 专项制作与复核。
- **权威参考层**：`standards/`，定义七个一级能力与 48 个二级能力的正式含义、方法和边界；`../sources/` 保留其引用的完整能力模型源文档。

运行层为正式标准提供可执行的工作规程，不能重写、缩窄或与其冲突。发生冲突时，以权威参考层为准；业务事实仍以当前任务中可追溯的来源为准。

### 原始档案链接说明

完整能力模型源文档保留了来源项目的 PDF 页码链接和项目知识索引链接，以保持原始转录的可追溯性。其中 PDF 未随来源材料提供，故不在本包伪造或替代；但 Markdown 已是该 313 页 PDF 的完整文本转录，含页码锚点、正文、表格、案例与历史记录，可独立支持本包运行与标准查阅。包内 [sources/README](../sources/README.md) 说明这一边界。该遗留的档案链接不是运行依赖，也不应被 Subagent 当成需要执行或读取的外部路径。

## 3. 不纳入的内容

本包不携带任何特定业务项目的需求、会议、Demo、个人资料、历史决定或行业事实；这些必须由新的调用者按任务输入契约提供。

除完整能力模型源文档外，未另行复制原始资料库中的历史案例、AI 阅读指引和冻结流程记录。它们不是运行本能力模型的正式定义，复制后反而会把来源项目的任务语境带入新项目。需要新增行业方法或案例时，应作为独立、可追溯的参考输入，而不是静默并入本包标准层。

## 4. 更新规则

1. 不得静默编辑 `standards/` 内的文件，也不得仅改运行层后声称标准已更新。
2. 更新正式标准时，创建新的包版本与新的冻结清单，保留旧版本和变更说明；不能覆盖已被项目引用的版本。
3. 正式标准更新后，复核 `01-22` 及 Demo 辅助 Skill 的兼容性、48 项索引和评估标尺；不兼容项明确标注待修订，不用旧解释掩盖差异。
4. 已确认的业务规则不因标准版本升级自动失效；应记录受影响范围、建议处理方式和是否需要人工复核。
