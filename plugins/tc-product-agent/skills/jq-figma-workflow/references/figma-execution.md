# Figma 生成与直接精修手册

只在实际 Figma 执行时读取。当前宿主的工具使用限制与必需操作指引仍适用；本手册不假定某个全局 `computer-use` Skill、固定运行库或桌面系统存在。没有可调用的底层工具就先引导配置，不编造点击或执行结果。

## 操作前

恢复本任务设计能力配置及 [Figma 执行前核对卡](../../tc-product-agent/references/18-Figma执行前核对卡.md)。核对任务包版本、实际应用/文件/页面/Frame、允许动作、保护对象、组件/素材和可观察验收。目标可读不证明可写；不得向错误文件提交提示词或把画布当前选择默认当成本任务目标。

主 Agent 已形成设计任务包时，沿用其中专业提示词与验收，不自行补业务规则；缺少事实先返回主线。旧页修改没有生成提示词也可直接精修，不为满足模板调用生成。

## Computer Use 的共同操作方法

1. 用当前宿主实际提供且获授权的界面观察能力定位应用，读取新鲜的无障碍信息或截图；核对真实文件、页面和目标对象。
2. 每次切换、点击、输入或提交后重新观察。页面变化后不复用旧元素索引或仅凭旧截图坐标连续操作。
3. 写入前确认选区、属性面板或输入框作用范围。多行提示词可用宿主支持的粘贴输入，发送前核对完整内容与目标；不通过未声明的系统脚本替代宿主规定路线。
4. 同一执行标识/步骤只提交一次。超时、失联或暂时看不到反馈标为结果未知，恢复后先查原执行，不能盲目重发造成重复页面。

## 旧页直接编辑

定位具体图层/组件与当前属性，优先复用实例、变量、字体、图标和已有资产；根据任务包调整文字、位置、尺寸、间距、布局或可见状态。不要让 Figma Agent 为局部问题重新生成整页。

每批修改后查看实际画面或导出，检查改动对象、相邻内容、全局菜单与共享组件影响；不要为一处修改删除动态状态或受保护图层。无法可靠定位时暂停该对象，返回具体缺口，不转用自然语言反复重画。

## 新整页生成（分「0→1 空白新建」与「存量风格延展」两条路）

1. **情况 A｜0→1 空白新建（目标 Figma 文件里还没有任何设计好的界面可参考）**：
   - **为什么不能在空白文件里直接调 Figma `Agents`**：空白文件没有既有界面和组件，Figma 云端 `Agents` 读不到本地 `component-recipes/`、`style-presets/` 和 `iconscout.py`，从零画只会徒手画出一堆没有样式的平涂丑方块。
   - **正确做法**：先在本地按 `$design-thinking-os` 运行 `component_recipe.py copy`、`style_preset.py`、`iconscout.py` 与成套头像/真图，搭出高保真 HTML/前端页面并跑通五大校验脚本；再调用 Figma MCP 的 `generate_figma_design` / `html_to_figma`（转为可编辑图层）或 `send_code_to_figma`（转为 Code Layer）一键导进目标 Figma 文件。

2. **情况 B｜存量风格延展（目标 Figma 文件里已经有其他设计好的界面了，或第 1 张核心代表页已导进 Figma）**：
   - **可以直接调用 Figma AI（Figma Agents）生成延展新页面**：
     - Codex 先根据 `design-decisions.md` 准备好新页面的功能模块与交互结构提示词；
     - **提示词中必须明确要求 Figma AI 参考并复用当前文件里已有的界面/Frame（写清要参考的已有页面/Frame 名称与节点，或附上已有界面截图）**，沿用既有页面的背景、卡片层级、按钮样式、圆角与字阶；
     - 提交生成后检查真实图层，再将从 IconScout / `real_image.py` 检索好的真实素材带入做局部精修，最后还原到可交互 Demo。

无基线的三套风格候选保持同一代表页、内容和状态，均在授权目标内；由主 Agent 收集选择后再扩展。有有效设计基线则沿用，不为每个新增页重选风格。

## 核验、停止与返回

按任务包的验收项对照实际画面，检查文字、结构、组件、关键状态和范围。保存实际结果链接、节点及截图/导出；未观察的交互不能由截图推断通过。

回传任务包版本、执行标识、实际改动/生成范围、结果证据、已通过/未通过/未观察项、保护范围影响与下一动作。提示词已发、Agent 运行完成和产品审阅通过是不同事实。

收到停止要求立即停止新动作。已有外部生成正在运行时，只在真实观察到停止后报告已停止；否则保留结果未知及已有产物，恢复前先核对原执行，不删除历史或晚到结果。
